# 🛍️ Product Catalog API: Swagger & Docs-as-Code

A lightweight Node.js/Express REST API demonstrating professional API documentation using **Swagger (OpenAPI 3.0)** and **Docs-as-Code** principles.

## 🎯 The Goal

In modern software development, Developer Experience (DX) is just as important as the code itself. Writing documentation in isolated, static documents leads to outdated information.

This project demonstrates how to bridge the gap between engineering and documentation by embedding **Swagger UI** directly into the codebase. This ensures the documentation lives alongside the code, stays up-to-date, and provides an interactive testing interface for frontend developers and API consumers.

## 🚀 Tech Stack

* **Backend:** Node.js, Express.js
* **Documentation:** Swagger UI Express, Swagger JSDoc, OpenAPI 3.0 Standard
* **Architecture:** RESTful API

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone [https://github.com/whoismarce/api-swagger-docs.git](https://github.com/whoismarce/api-swagger-docs.git)
   ```

1. Install dependencies:

```Bash
npm install

```

1. Start the server:

```Bash
node index.js

```

1. Access the interactive API documentation at:
👉 [Swagger UI](http://localhost:3000/api-docs)

## 📝 Key Features

* Interactive UI: Consumers can test endpoints directly from the browser using the "Try it out" feature.
